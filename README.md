# sky-creator-pro
Website for a video editor

## Sky AI

The `sky-ai/` folder holds Sky AI, Sky the Goat's assistant fine-tuned from Qwen3 with 4-bit QLoRA, and **Sky AI Ultra**, the desktop app to chat with it. Double-click `sky-ai/start_sky_ai.bat` to start. See [sky-ai/README.md](sky-ai/README.md).
