# Sky Creator Pro
topics: sky creator pro, skycreatorpro, mega pro, thumbnail maker, video editor

## Key facts [core]
- Sky Creator Pro is a free video editor and thumbnail maker for creators, made by Sky the Goat.
- Windows desktop app (Electron) plus a website, skycreatorpro.com, where you create an account and download it.
- Core editing is free forever, with no locked basic editing tools.

## Features
- Timeline video editing: import media, trim clip start and end, split at playhead, change speed, rename, duplicate and delete clips, add text, undo and redo.
- Export at 1080p, or vertical 1080x1920 for Shorts. Export settings include resolution and frame rate.
- Thumbnail maker: choose a layout style, add thumbnail text, export the thumbnail.
- Save projects to the cloud and load them later. Creator project dashboard.
- Sky the Goat has shown AI creator tools on YouTube, including an AI scheduler.

## Mega Pro
- Optional plan for future AI tools, AI credits, cloud/project sync and early access.
- It was in test mode; payments were not live. Core editing stays free.

## Tech
- Built with React, TypeScript and Vite; Electron for the desktop app; Supabase for accounts and cloud storage; Netlify for the website.
